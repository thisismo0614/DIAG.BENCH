Windows 보안 경고에 대하여

처음 실행할 때 Windows SmartScreen 경고가 표시될 수 있습니다. 이는 파일에 문제가 있다는 뜻이 아니라, 아직 다운로드 기록이 충분히 쌓이지 않은 새 프로그램에 표시되는 화면입니다.

코드 서명과 SmartScreen 평판은 서로 다른 시스템입니다. 코드 서명은 배포자 확인과 파일 변조 여부 검증에 쓰이고, SmartScreen 평판은 다운로드·실행 이력이 쌓이면서 별도로 형성됩니다. 따라서 서명이 있어도 새로 배포된 버전에는 한동안 경고가 표시될 수 있습니다.

가장 확실한 확인 방법은 위의 SHA-256 체크섬 비교입니다. 배포는 항상 GitHub 릴리스를 통해서만 이루어지며, 다른 경로로 배포된 파일은 이 프로젝트와 무관합니다.
