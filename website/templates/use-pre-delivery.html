조립 PC 출고 검사

조립을 마치고 부팅이 되면 끝난 것 같지만, 부팅이 된다는 것과 사양대로 동작한다는 것은 다릅니다. 메모리가 절반 속도로 돌거나, 듀얼 채널이 안 잡혔거나, 부하를 걸면 온도가 치솟는 상태로도 부팅은 잘 됩니다. 보내기 전에 확인할 것을 정리했습니다.

부팅 성공은 검사가 아닙니다

출고 후 들어오는 문의의 상당수는 조립 단계에서 확인했으면 걸렀을 것들입니다.

  • "게임이 생각보다 느려요" → 메모리가 싱글 채널이었음
  • "3200 램인데 2666으로 나와요" → XMP를 안 켰음
  • "조금 하면 뜨거워지고 느려져요" → 쿨러 장착 불량, 부하 시 온도 미확인
  • "가끔 꺼져요" → 부하 상태에서 검증하지 않음

전부 출고 전 몇 분이면 확인되는 것들입니다.

확인 항목

1. 사양대로 인식됐는가

확인흔한 실수
메모리 용량과 개수 한 개가 덜 꽂혀 있거나 인식이 안 됨. 용량만 보면 놓치기 쉽습니다.
듀얼 채널 구성 같은 채널에 나란히 꽂음. A2/B2가 아니라 A1/A2
메모리 동작 속도 XMP/EXPO 미적용. 기본값은 항상 낮습니다.
저장장치 전부 인식 NVMe 슬롯 위치에 따라 SATA 포트가 비활성화되는 보드가 있습니다.
그래픽카드 인식과 드라이버 드라이버 미설치 상태로 출고. 장치 관리자 오류도 함께 확인하세요.
새 디스크의 SMART 새 제품도 초기 불량이 있습니다. 사용 시간이 0에 가까운지도 함께 확인하면 새 부품이 맞는지가 확인됩니다.

2. 부하 상태에서 안정적인가

가장 중요하면서 가장 자주 생략되는 단계입니다. 유휴 상태의 온도는 아무것도 증명하지 않습니다. 쿨러가 제대로 안 붙어 있어도 유휴 온도는 정상으로 보입니다.

  • CPU 부하 테스트 — 온도가 안정 구간에 머무는지, 스로틀링이 걸리는지
  • 메모리 검사 — XMP를 켰다면 반드시 돌려야 합니다. 부팅된다고 안정적인 것이 아닙니다.
  • GPU 부하 테스트 — 온도와 전력 제한 동작 확인

온도를 읽을 수 없는 상태로 부하 테스트를 돌리지 마세요. 온도 기반 안전 중단이 동작하지 않습니다. Windows에서 CPU 온도를 읽으려면 관리자 권한이 필요하며, 권한이 없으면 "센서가 없다"고 표시되는 경우가 많습니다. 출고 검사는 관리자 권한으로 실행하세요.

3. 오류 기록이 깨끗한가

조립·테스트 과정에서 발생한 WHEA 오류나 예기치 않은 종료가 남아 있는지 확인합니다. 조립 중 발생한 것이라면 출고 전에 원인을 찾아야 합니다.

검사 순서

  1. Windows 설치와 드라이버 설치를 마칩니다. 드라이버가 없으면 장치가 제대로 보고되지 않아 검사 결과가 왜곡됩니다.
  2. BIOS에서 XMP/EXPO를 적용합니다. 사양서에 적힌 속도로 팔았다면 켜야 그 속도가 나옵니다.
  3. 관리자 권한으로 출고 검사 프로필을 실행합니다. DIAG.BENCH의 출고 전 검사 프로필은 약 2분 30초가 걸리며, 구성 확인과 부하 테스트를 함께 수행합니다.
  4. "검사하지 않음"과 "확인 불가" 항목을 확인합니다. 이것들은 정상이 아닙니다. 출고 검사에서는 미확인 항목을 남기지 않는 것이 목표입니다.
  5. 문제가 있으면 고치고 다시 측정합니다. 고쳤다고 생각한 것이 실제로 값에 반영됐는지 확인하는 것까지가 한 세트입니다.
  6. 검사 성적서를 발급해 동봉합니다.

검사 성적서를 함께 보내면

출고 시점의 상태를 문서로 남겨두면 양쪽 모두에게 이롭습니다.

  • 구매자는 사양대로 조립됐다는 것을 숫자로 확인할 수 있습니다. "3200MHz로 동작 중"이라고 적혀 있으면 의심할 이유가 없습니다.
  • 판매자는 출고 시점의 상태를 증명할 수 있습니다. 이후 문제가 생겨도 언제부터의 문제인지 구분됩니다.
  • 검증 해시가 함께 발급되어, 문서가 나중에 수정되지 않았음을 확인할 수 있습니다.

새 디스크의 사용 시간이 0시간에 가깝다는 기록이 남는다는 점도 실질적인 가치가 있습니다 — 중고 부품을 새것으로 팔지 않았다는 증거가 되기 때문입니다.
