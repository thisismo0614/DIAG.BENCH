이 도구가 다른 점

검사하지 않은 것을 정상이라고 하지 않습니다

실행하지 않은 검사는 "이상 없음"이 아니라 "검사 안 함"으로 표시됩니다. 결과를 판단할 수 없으면 정상으로 넘기지 않고 "판단 보류"로 남깁니다.

관측한 사실과 추정한 원인을 구분합니다

"온도가 88°C다"는 측정값이고 "쿨러가 고장났다"는 추정입니다. 원인은 하나로 단정하지 않고 후보를 나열하며, 각 판정에 실제 측정값을 근거로 붙입니다.

확인 방법을 함께 알려줍니다

문제를 찾으면 조치 방법과 재검사 방법까지 제시합니다. 조치 전후를 비교해 실제로 개선됐는지 확인할 수 있습니다.

주요 기능

하드웨어 진단

CPU·GPU·메모리·저장장치·네트워크·디스플레이·드라이버·Windows 이벤트 로그 8개 영역을 검사하고, 각 항목마다 판정 근거를 남깁니다.

저장장치 SMART 상세 분석

전체 판정(PASSED/FAILED)만 보지 않습니다. 읽기 실패 섹터·재할당 섹터·SSD 수명· 사용 시간까지 개별 속성을 읽어, "PASSED인데 상태가 나빠지고 있는 디스크"를 찾아냅니다.

부하 테스트 5종

CPU·저장장치·RAM·GPU·VRAM에 실제로 부하를 걸어 확인합니다. 온도가 안전 한계를 넘으면 자동으로 중단하며, 부하가 실제로 걸렸는지까지 검증합니다.

실시간 모니터링

CPU·GPU·메모리의 사용률·온도·클럭을 1초 간격으로 관찰합니다. 문제가 발생하는 순간을 기록해 JSON으로 저장할 수 있습니다.

상관관계 분석

지금 측정한 상태와 최근 Windows 이벤트 기록을 대조합니다. 둘 다 있을 때만 서로를 근거로 삼아, 근거 없는 확신을 만들지 않습니다.

판매용 점검 리포트

중고 거래 시 구매자에게 넘길 수 있는 상태 점검 문서를 만듭니다. 하드웨어 식별값, 검사 범위, 등급, 위변조 감지 해시, SMART 측정값 원본이 포함됩니다.

주변기기 개별 테스트

마우스 더블클릭 오작동, 키보드 채터링, 모니터 불량화소·잔상, 인터넷 핑·지터·손실을 각각 확인할 수 있습니다.

진단 기록과 전후 비교

진단 결과를 기록해두고 다음 진단과 비교합니다. 조치 후 온도가 실제로 내려갔는지 숫자로 확인할 수 있습니다.

프로그램 없이도 도움이 되도록

진단 결과를 읽는 법과 문제를 좁혀 나가는 순서를 문서로 공개합니다. 전부 실제로 측정해 확인한 내용입니다.

문제 해결 가이드

증상별로 원인을 좁혀 나가는 방법

메모리 속도, 듀얼 채널, 오버클럭 흔적, 배터리 열화, 유휴 온도 상승 등 자주 나타나는 문제의 원인과 단계별 절차를 위험도와 함께 안내합니다.

 기술 해설

왜 그렇게 나오는지 알고 보면 다릅니다

CPU 온도가 안 보이는 이유, 배터리 설계 용량을 얻는 방법, SMART에서 실제로 봐야 할 항목, VRAM 표기가 제각각인 이유.

 활용

중고 PC 살 때 확인해야 할 것

겉모습으로 알 수 없는 다섯 가지 — 실제 사용 시간, 디스크 손상 이력, 배터리 열화, 이전 사용자의 설정, 최근 오류 기록.

 사용 설명서

설치부터 리포트 발급까지

결과 읽는 법, 목적별 검사, 평소 상태 기준선, 안정성 테스트, 점검 리포트와 전후 비교를 순서대로 설명합니다.

미리 알아두실 것

과장하지 않기 위해, 이 도구가 하지 못하는 것도 함께 적습니다.

  • GPU 실시간 정보는 NVIDIA만 지원합니다. AMD·Intel GPU는 모델명과 VRAM 용량까지만 확인됩니다.
  • RAM 검사는 간이 검사입니다. MemTest86 같은 부팅형 정밀 검사를 대체하지 않으며, 어느 슬롯의 모듈이 불량인지는 알 수 없습니다.
  • CPU 온도를 읽으려면 관리자 권한이 필요합니다. 일반 권한으로 실행하면 온도 항목이 비어 있고, 부하 테스트는 온도 기반 안전장치 없이 시간 제한 모드로만 동작합니다. 그 사실과 이유를 화면에 표시하며, 승격 실행을 안내합니다. (왜 그런지)
  • 고장 원인을 확정하지 않습니다. 가능성이 높은 후보와 확인 순서를 제시하는 도구입니다.
  • 점검 리포트는 법적 인증서가 아닙니다. 정부의 성능인증(EPC) 제도와 무관합니다.
