기술 해설 · 메모리

XMP·EXPO란 무엇인가

3200MHz라고 적힌 메모리를 샀는데 2666으로 표시됩니다. 불량을 받은 걸까요? 거의 확실히 아닙니다. 메모리는 기본적으로 표준 속도로 동작하도록 설계되어 있고, 상자에 적힌 속도는 따로 켜야 나옵니다.

왜 처음부터 제 속도로 안 도는가

메모리 모듈 안에는 SPD라는 작은 칩이 있어서 "나는 이런 속도로 동작할 수 있다"는 정보를 담고 있습니다. 여기에는 두 종류의 설정이 들어 있습니다.

구분내용언제 쓰이나
JEDEC 표준 업계 표준으로 정한 보수적인 속도
(DDR4는 보통 2133~2666)		 기본값. 아무 설정도 안 하면 이걸로 동작합니다
XMP / EXPO 제조사가 "이 속도까지 검증했다"고 넣어둔 프로파일
(상자에 적힌 속도)		 BIOS에서 사용자가 켜야 적용됩니다

기본값이 낮은 이유는 호환성입니다. 어떤 메인보드에, 어떤 CPU와, 몇 개를 꽂을지 제조사는 알 수 없습니다. 그래서 어떤 조합에서도 부팅은 되는 속도를 기본으로 두고, 더 빠른 설정은 사용자가 선택하도록 남겨둡니다.

XMP는 Intel이, EXPO는 AMD가 만든 이름입니다. 하는 일은 같습니다 — 검증된 속도·타이밍·전압 묶음을 한 번에 적용합니다. 메인보드 제조사에 따라 "D.O.C.P", "A-XMP" 같은 다른 이름으로 부르기도 합니다.

속도를 올리면 실제로 얼마나 빨라지나

솔직하게 말하면 용도에 따라 차이가 큽니다. 과장된 기대는 하지 않는 편이 좋습니다.

  • 내장 그래픽 사용 — 체감 차이가 가장 큽니다. 내장 그래픽은 시스템 메모리를 그래픽 메모리로 쓰기 때문에 대역폭이 곧 성능입니다.
  • Ryzen CPU — 메모리 속도가 내부 통신 속도와 연결되어 있어 영향이 상대적으로 큽니다.
  • 일반적인 문서 작업·웹 브라우징 — 체감하기 어렵습니다.
  • 게임 — 그래픽카드가 병목인 경우가 많아 차이가 작을 수 있습니다.

켜기 전에 알아둘 것

BIOS 설정 변경은 되돌리기 어려운 축에 듭니다. 잘못 설정하면 부팅이 되지 않을 수 있고, 그때는 화면이 안 나오니 되돌릴 방법을 미리 알아둬야 합니다. 메인보드의 CMOS 클리어(점퍼나 버튼, 혹은 수은전지 분리)가 그 방법입니다. 내 메인보드에서 어떻게 하는지 먼저 확인해 두세요.

  1. 현재 설정을 기록합니다. BIOS 화면을 사진으로 찍어두면 충분합니다.
  2. 바꾸기 전 상태에서 안정성을 확인합니다. 지금도 불안정한데 설정을 바꾸면 무엇이 원인인지 알 수 없게 됩니다. 기준점을 먼저 만드세요.
  3. 프로파일을 켭니다. BIOS에서 XMP/EXPO를 Profile 1로 설정합니다.
  4. 부팅되면 실제로 적용됐는지 확인합니다. 켰다고 항상 적용되는 것은 아닙니다.
  5. 메모리 검사를 돌립니다. 부팅이 된다고 안정적인 것이 아닙니다. 오류가 나오면 프로파일을 끄거나 한 단계 낮은 설정을 씁니다.

켰는데도 속도가 안 오르는 경우

  • 메인보드나 CPU의 상한에 걸림 — 메모리가 3600을 지원해도 보드가 3200까지만 지원하면 3200이 최대입니다.
  • 슬롯을 모두 채워서 — 4개 슬롯을 다 채우면 지원 속도 상한이 내려가는 보드가 많습니다. 메모리 컨트롤러 부담이 커지기 때문입니다.
  • 서로 다른 모듈이 섞여 있어서 — 이 경우 가장 낮은 공통 설정으로 동작합니다.

타이밍은 OS에서 읽을 수 없습니다

알아둘 만한 한계가 하나 있습니다. 메모리 성능은 속도(MHz)뿐 아니라 타이밍(CL16-18-18-38 같은 값)에도 좌우되는데, Windows에서 실행되는 프로그램은 현재 적용된 타이밍을 읽을 수 없습니다.

타이밍을 알려면 SPD 칩에 직접 접근해야 하고, 이는 커널 수준 권한이 필요합니다. DIAG.BENCH가 커널 드라이버를 설치하지 않기로 한 이상 이 값은 얻을 수 없습니다. 그래서 "타이밍은 확인할 수 없다"고 명시합니다 — 모르는 것을 아는 척하지 않기 위해서입니다. 정확한 타이밍이 필요하면 BIOS 화면에서 직접 확인하세요.
