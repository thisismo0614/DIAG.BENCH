자주 묻는 질문

DIAG.BENCH가 무엇인가요?

Windows PC의 하드웨어와 시스템 상태를 진단하는 데스크톱 프로그램입니다. CPU·GPU·메모리·저장장치·네트워크 등을 측정하고, 이상이 보이면 측정값을 근거로 원인 후보와 확인 방법을 제시합니다. 단순히 수치를 나열하는 도구가 아니라 "무엇이 문제인지, 무엇을 먼저 확인해야 하는지"를 알려주는 것을 목표로 합니다.

어떤 Windows 버전을 지원하나요?

{{MIN_WINDOWS}}에서 동작합니다. 64비트(x64) 전용이며 32비트와 ARM은 지원하지 않습니다. Windows가 아닌 운영체제는 지원하지 않습니다.

무료인가요?

네. 완전히 무료이며 오픈소스(MIT 라이선스)입니다. 결제·계정 등록·구독이 없고, 기능 제한판이나 유료 업그레이드도 없습니다.

어디서 다운로드하나요?

다운로드 페이지에서 받으실 수 있습니다. 모든 공식 배포는 GitHub 릴리스를 통해서만 이루어집니다. 다른 사이트에서 배포되는 파일은 이 프로젝트와 무관하며 안전을 보장할 수 없습니다.

Windows 릴리스는 코드 서명되어 있나요?

릴리스마다 서명 여부를 릴리스 노트에 명확히 표시합니다. 서명된 빌드는 다운로드 후 PowerShell에서 직접 확인하실 수 있습니다.

Get-AuthenticodeSignature ".\파일명.exe"

다만 코드 서명과 SmartScreen 평판은 별개입니다. 서명이 있어도 새로 배포된 버전은 다운로드 기록이 쌓이기 전까지 경고가 표시될 수 있습니다. 무결성을 가장 확실하게 확인하는 방법은 릴리스에 함께 올라오는 SHA256SUMS.txt와 비교하는 것입니다.

제 PC 정보가 외부로 전송되나요?

아니요. 진단은 전부 로컬에서 실행되며 결과를 서버로 보내지 않습니다. 계정 등록도 없습니다. 인터넷 연결은 네트워크 속도 테스트를 직접 실행할 때만 사용합니다. 점검 리포트의 QR 코드도 로컬에서 생성됩니다 — 서버에 조회해서 받아오는 값이 아닙니다.

QR을 스캔하면 리포트 검증 페이지가 열립니다. 이때도 리포트 번호와 검증코드는 주소의 # 뒤에 실려 가는데, 브라우저는 이 부분을 서버로 전송하지 않습니다. 검증할 파일을 올려도 업로드되지 않고 브라우저 안에서 해시만 다시 계산합니다.

왜 GPU 정보가 일부만 나오나요?

GPU의 실시간 온도·클럭·사용률은 nvidia-smi를 통해 읽기 때문에 NVIDIA 그래픽카드에서만 확인됩니다. AMD·Intel GPU는 모델명과 VRAM 용량까지만 표시되며, 이 경우 프로그램은 "정상"이라고 하지 않고 "확인하지 못함"으로 표시합니다.

RAM 검사가 MemTest86을 대체하나요?

아니요. 이 프로그램의 RAM 검사는 소프트웨어 자가점검입니다. 운영체제가 할당해준 메모리 영역만 검사할 수 있어, 물리 메모리 전체를 검사하거나 어느 슬롯의 모듈이 불량인지 알아내지는 못합니다. 오류가 발견되면 MemTest86 같은 부팅형 정밀 검사로 교차 확인하시기를 안내합니다.

점검 리포트를 중고 거래에 써도 되나요?

참고 자료로 활용하실 수 있도록 만들었습니다. 하드웨어 식별값, 검사 범위, SMART 측정값 원본, 위변조 감지 해시가 포함됩니다.

다만 이 문서는 법적 인증서가 아니며 정부의 성능인증(EPC) 제도와 무관합니다. "검사를 완료했다"와 "고장이 없다"는 다른 의미이고, 검사 범위 밖 항목은 확인되지 않았음을 리포트 본문에 명시합니다. 또한 위변조 감지는 문서 내용이 바뀌었는지를 확인하는 것이지, 발급자가 처음부터 조작하는 것까지 막지는 못합니다.

소스 코드는 어디에 있나요?

GitHub 저장소에 전체가 공개되어 있습니다. 진단 규칙과 판정 임계값도 모두 코드에 있으므로, 어떤 근거로 판정이 나왔는지 직접 확인하실 수 있습니다.

버그를 발견했거나 판정이 이상합니다. 어떻게 알리나요?

GitHub Issues에 남겨주세요. 특히 "멀쩡한데 문제가 있다고 나온다"거나 그 반대인 경우가 가장 중요한 제보입니다. 가능하면 사용 중인 하드웨어 구성과 화면에 표시된 판정 근거를 함께 알려주시면 도움이 됩니다.

왜 smartctl.exe가 함께 설치되나요?

저장장치의 SMART 정보를 읽기 위해 smartmontools의 smartctl.exe를 동봉합니다. 사용자가 별도로 설치하지 않아도 되도록 하기 위해서입니다. 이 프로그램은 GPL v2 라이선스이며, 관련 고지는 서드파티 고지에서 확인하실 수 있습니다.
