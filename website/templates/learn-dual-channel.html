듀얼 채널 확인하는 법

메모리를 두 개 꽂았다고 자동으로 듀얼 채널이 되지 않습니다. 어느 슬롯에 꽂았느냐에 따라 대역폭이 두 배가 되기도, 그대로이기도 합니다. 비용이 전혀 들지 않는데 놓치기 쉬운 부분입니다.

채널이 무엇인가

CPU의 메모리 컨트롤러는 메모리와 여러 개의 독립된 통로로 연결됩니다. 이 통로 하나가 채널입니다. 일반 데스크톱 CPU는 보통 채널이 두 개입니다.

  • 두 채널에 하나씩 꽂으면 → 두 통로를 동시에 씁니다. 대역폭 2배
  • 한 채널에 두 개 꽂으면 → 통로 하나만 씁니다. 대역폭 그대로

용량은 어느 쪽이든 같습니다. 8GB 두 개면 16GB입니다. 달라지는 것은 속도뿐이라 눈치채기 어렵습니다.

슬롯 배치 — 왜 한 칸 띄우는가

메인보드의 메모리 슬롯 4개는 보통 이렇게 배치되어 있습니다.

CPU 쪽                                      바깥쪽
 ┌──────┬──────┬──────┬──────┐
 │  A1  │  A2  │  B1  │  B2  │
 └──────┴──────┴──────┴──────┘
   채널 A        채널 B

여기서 A1과 A2는 같은 채널입니다. 두 개를 나란히 꽂으면 싱글 채널이 됩니다. 두 개를 쓸 때는 A2와 B2에 꽂아야 합니다 — 채널이 서로 다르기 때문입니다. 메인보드 설명서에서 "2개 장착 시 권장 슬롯"으로 표시된 자리가 대개 여기입니다.

왜 A1/B1이 아니라 A2/B2인가. 신호 품질 때문입니다. CPU에서 먼 슬롯을 쓰면 신호 반사가 줄어 높은 속도에서 더 안정적입니다. 다만 보드마다 표기와 권장 배치가 다릅니다. 설명서를 확인하는 것이 확실합니다. 슬롯 옆에 흰색·검은색으로 색을 구분해 둔 보드도 많은데, 대개 같은 색이 한 쌍입니다.

지금 듀얼 채널인지 확인하는 방법

PowerShell로 슬롯 위치 보기

Get-CimInstance Win32_PhysicalMemory |
  Select-Object DeviceLocator, BankLabel, Capacity, Speed

DeviceLocator나 BankLabel에 DIMM_A2, DIMM_B2처럼 슬롯 이름이 나옵니다. 서로 다른 문자(A와 B)가 보이면 듀얼 채널, 같은 문자만 있으면 싱글 채널입니다.

표기가 보드마다 제각각입니다. ChannelA-DIMM1처럼 명확한 보드도 있고, DIMM 0, DIMM 1처럼 채널을 알 수 없게 적는 보드도 있습니다. 후자라면 소프트웨어만으로는 확실히 판단할 수 없습니다. 케이스를 열어 실제 꽂힌 위치를 눈으로 보는 것이 가장 확실합니다.

작업 관리자로 보기

작업 관리자 → 성능 → 메모리에서 "슬롯 사용" 항목으로 몇 개 슬롯을 썼는지는 알 수 있습니다. 다만 채널 구성까지는 알려주지 않습니다.

용량이 다른 모듈을 섞어도 되나

됩니다. 요즘 메인보드는 플렉스 모드를 지원해서, 8GB + 16GB를 꽂으면 겹치는 8GB 구간은 듀얼 채널로, 나머지 8GB는 싱글 채널로 동작합니다. 전부 싱글보다는 낫습니다.

다만 속도는 별개 문제입니다. 사양이 다른 모듈이 섞이면 가장 낮은 공통 설정으로 맞춰집니다. 가능하면 같은 모델로 맞추는 것이 가장 확실합니다.

얼마나 차이가 나는가

  • 내장 그래픽 — 차이가 큽니다. 내장 그래픽은 시스템 메모리를 그래픽 메모리로 쓰기 때문에 대역폭이 곧 성능입니다. 싱글 채널이면 성능이 크게 떨어집니다. VRAM이 어떻게 할당되는지도 함께 보면 이해가 쉽습니다.
  • 외장 그래픽카드가 있는 게임 — 차이가 작습니다. 대개 그래픽카드가 병목입니다.
  • 일반 작업 — 체감하기 어렵습니다.

그래도 슬롯만 바꿔 꽂으면 되는 일이므로, 확인해서 아니라면 고칠 가치는 충분합니다.

옮겨 꽂는 순서

  1. 메인보드 설명서에서 2개 장착 시 권장 슬롯을 확인합니다.
  2. 전원을 완전히 끄고 코드를 뽑습니다. 대기 전원이 남아 있으면 안 됩니다. 전원 버튼을 몇 초 눌러 잔류 전원을 뺍니다.
  3. 슬롯 양옆(또는 한쪽) 걸쇠를 열고 모듈을 뺍니다.
  4. 권장 슬롯에 딸깍 소리가 날 때까지 확실히 눌러 넣습니다. 덜 꽂히면 부팅이 안 되거나 인식이 안 됩니다.
  5. 부팅 후 다시 확인해 채널이 나뉘었는지 봅니다.
