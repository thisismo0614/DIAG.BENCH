개인정보처리방침

이 문서는 웹사이트와 프로그램을 나누어 설명합니다. 둘은 다루는 정보가 다릅니다. 지키지 못할 약속은 적지 않았고, 우리가 통제하지 못하는 부분도 그대로 밝혔습니다.

한 줄 요약

웹사이트는 방문자 정보를 수집하지 않고, 프로그램은 진단 결과를 사용자 PC에만 저장합니다.

1. 웹사이트

수집하지 않는 것

  • 쿠키를 사용하지 않습니다. 로그인도 장바구니도 없는 정적 페이지입니다.
  • 분석 도구를 넣지 않았습니다. Google Analytics 등 방문자 추적 스크립트가 없습니다.
  • 입력 양식이 없습니다. 이름·이메일을 받는 곳이 아예 없습니다.
  • 광고를 게재하지 않습니다. 광고망 추적 스크립트도 없습니다.

외부로 요청이 나가지 않습니다

많은 사이트가 글꼴·아이콘·스크립트를 외부 CDN에서 받아옵니다. 그렇게 하면 방문자의 IP 주소가 그 회사들에 전달됩니다. 이 사이트는 그러지 않습니다.

  • 글꼴은 직접 서브셋해 이 사이트에서 제공합니다 (외부 글꼴 서비스를 쓰지 않습니다).
  • 실행되는 자바스크립트가 없습니다.
  • 페이지를 여는 데 필요한 요청은 이 사이트 안에서만 일어납니다.

우리가 통제하지 못하는 부분

이 사이트는 GitHub Pages에서 제공됩니다. 따라서 페이지를 여는 순간 GitHub의 서버에는 접속 기록(IP 주소, 브라우저 정보 등)이 남을 수 있습니다. 이는 GitHub이 서비스를 운영하기 위해 처리하는 것이며 우리가 열람하거나 통제하지 않습니다. 자세한 내용은 GitHub 개인정보 보호 정책을 참고하세요.

다운로드 버튼을 누르면 파일은 GitHub Releases에서 내려받습니다. 이때도 마찬가지로 GitHub 쪽에 요청 기록이 남습니다.

2. 프로그램 (DIAG.BENCH 앱)

무엇을 읽는가

진단을 위해 PC의 하드웨어·시스템 정보를 읽습니다 — CPU·GPU·메모리·저장장치 모델과 상태, 네트워크 연결 상태, Windows 이벤트 로그의 오류 기록 등입니다. 문서·사진·브라우저 기록 같은 개인 파일은 읽지 않습니다.

어디에 저장되는가

진단 결과와 설정은 사용자 PC 안에만 저장됩니다. Windows 사용자 폴더 아래 앱 데이터 위치에 JSON 파일로 남습니다.

외부로 전송하지 않습니다. 진단 결과를 보내는 서버가 없습니다. 계정도, 로그인도, 사용 통계 수집도 없습니다. 프로그램을 지우면 저장된 기록도 함께 사라집니다.

점검 리포트에 담기는 정보

점검 리포트를 발급하면 하드웨어 식별 정보와 측정값이 문서에 포함됩니다. 수리점 기록 기능을 쓰면 사용자가 직접 입력한 고객명·접수번호·메모도 함께 저장됩니다.

이 정보 역시 사용자 PC에만 남습니다. 다만 리포트 파일을 다른 사람에게 전달하면 그 안의 내용도 함께 전달된다는 점은 사용자가 판단해야 합니다. 중고 거래나 수리 인수인계에 쓰라고 만든 기능이므로, 넘기기 전에 내용을 확인하세요.

네트워크를 쓰는 경우

다음 두 가지에서만 네트워크가 사용되며, 둘 다 사용자가 실행할 때만 일어납니다.

  • 인터넷 연결 테스트 — 응답 시간을 재기 위해 외부 서버에 신호를 보냅니다.
  • 업데이트 확인 — 새 버전이 있는지 GitHub에 조회합니다.

어느 쪽도 진단 결과나 PC 정보를 함께 보내지 않습니다.

3. 이 말을 믿지 않아도 됩니다

개인정보처리방침은 대개 확인할 방법이 없는 약속입니다. 이 프로젝트는 다릅니다 — 전체 소스 코드가 공개되어 있습니다.

어떤 값을 어디서 읽는지, 어디에 저장하는지, 네트워크를 언제 쓰는지 코드에서 직접 확인할 수 있습니다. 기술 문서의 저장 데이터 항목에 저장 위치와 형식이 정리되어 있습니다.

4. 변경

이 방침이 바뀌면 이 페이지를 갱신합니다. 수집 항목이 늘어나는 변경(예: 분석 도구 도입, 광고 게재)이 있을 경우 여기에 명시적으로 적습니다. 조용히 바꾸지 않습니다.

이 페이지의 변경 이력은 저장소 커밋 기록에 전부 남아 있어 언제 무엇이 바뀌었는지 확인할 수 있습니다.

5. 문의

이 방침이나 데이터 취급에 관한 질문은 GitHub Issues로 남겨주세요.
