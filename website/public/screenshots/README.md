# 스크린샷

이 폴더에 실제 앱 스크린샷을 넣으면 사이트에서 사용할 수 있습니다.

아직 비어 있는 이유: **가짜 스크린샷을 만들지 않기 위해서**입니다.
실제 화면을 캡처해서 여기에 넣은 뒤 템플릿에서 참조하세요.

권장:
- `dashboard.png` — 전체 진단 결과 화면
- `inspection-report.png` — 판매용 점검 리포트
- `stability.png` — 안정성(부하) 테스트 화면
- `monitoring.png` — 실시간 모니터링

권장 사양: 가로 1600px 이상, PNG. 개인 식별 정보(시리얼 전체값 등)가 보이지 않도록 주의하세요.
