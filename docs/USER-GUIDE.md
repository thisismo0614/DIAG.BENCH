# DIAG.BENCH 사용 설명서

PC의 상태를 검사하고, 문제의 원인을 좁히고, 그 결과를 문서로 남기는 방법.
이 프로그램이 무엇을 확인했고 **무엇을 확인하지 않았는지**를 읽는 법까지 설명합니다.

> 이 문서는 앱 0.26.0 기준입니다. 화면 구성과 판정 기준은 버전에 따라 달라지며,
> 각 리포트에는 그 리포트를 만든 버전이 함께 기록됩니다.

기술적인 내부 동작은 [TECHNICAL.md](TECHNICAL.md)를 보세요.

## 1. 설치와 첫 실행

설치 파일은 `DIAG.BENCH-Setup-<버전>-win-x64.exe`입니다. 설치 중 위치를 직접 고를 수 있습니다.
지원 환경은 **Windows 10 (x64) 이상**입니다.

### ⚠ 설치 시 경고가 뜹니다

현재 버전은 **코드 서명이 되어 있지 않습니다.** 실행하면 Windows SmartScreen이
"Windows의 PC 보호" 화면을 띄웁니다. **추가 정보 → 실행**을 누르면 설치가 진행됩니다.

서명은 인증서가 있어야 가능하고 현재 발급 심사 중입니다. 서명된 버전이 나오기 전까지는
이 경고가 계속 뜹니다.

### 받은 파일이 맞는지 확인하려면

```powershell
Get-FileHash ".\DIAG.BENCH-Setup-0.26.0-win-x64.exe" -Algorithm SHA256
```

나온 값이 배포처에 적힌 SHA-256과 같은지 비교합니다.

### 관리자 권한

평소에는 **관리자 권한 없이** 실행합니다. 일부 저장장치의 SMART 정보를 읽지 못했을 때만,
해당 장치 하나에 대해 **"관리자 권한으로 재검사"** 버튼이 나타납니다. 이때만 UAC 승인 창이 뜹니다.

## 2. 처음 5분

1. **대시보드에서 전체 진단을 한 번 돌립니다.** 증상 6가지 중 하나를 고르면 관련 항목을
   앞쪽에 배치해 보여줍니다. 잘 모르겠으면 "전체 진단"을 고르세요.
2. **결과에서 회색 "검사 안 함" 항목이 있는지 먼저 봅니다.** 초록색만 세지 마세요. ([4장](#4-결과-읽는-법))
3. **왼쪽 아래 표시 모드를 "전문가"로 바꿔 같은 결과를 다시 봅니다.** 판정은 그대로이고
   근거·측정값·규칙 ID가 함께 보입니다.
4. **"평소 상태 기준선"에서 기준선을 한 번 측정해 둡니다.** 약 33초.
   이후 진단부터 "평소보다 몇 도 높음"을 알려줍니다.
5. **"목적별 검사"에서 용도에 맞는 프로필을 골라 봅니다.** 중고 거래·수리·출고 검사는
   여기서 시작합니다.

## 4. 결과 읽는 법

가장 중요한 장입니다. 색깔만 보지 말고 **어떤 상태로 분류됐는지**를 보세요.

### 결과 상태 6가지

| 표시 | 뜻 | 어떻게 받아들일까 |
|---|---|---|
| **이상 없음** | 검사했고 문제를 찾지 못함 | 이 검사 범위 안에서는 괜찮습니다 |
| **주의** | 이상 가능성은 있으나 고장으로 단정할 수 없음 | 지켜보거나 권장 조치를 확인 |
| **오류 확인됨** | 실제 오류가 측정됨 | 조치가 필요합니다 |
| **위험** | 사용 중단이나 즉시 조치가 권장되는 수준 | 데이터 백업부터 하세요 |
| **검사 안 함** | 측정하지 못했거나 이 프로필이 하지 않는 검사 | **정상이라는 뜻이 절대 아닙니다** |
| **판단 보류** | 검사는 했으나 판단할 근거가 부족함 | 조건을 바꿔 다시 검사 |

### 🔴 이 프로그램의 핵심 약속

**검사하지 않은 것을 정상이라고 말하지 않습니다.** 다른 진단 프로그램은 읽지 못한 항목을
조용히 넘기거나 초록색으로 표시하곤 합니다. 여기서는 **검사 안 함**으로 따로 구분하고,
왜 못 했는지 사유를 함께 적습니다.

그래서 **전부 초록색이 아닌 것이 정상입니다.** 회색 항목이 보인다면 그건 결함이 아니라
정직한 보고입니다.

### "검사 안 함"이 뜨는 이유

- **이 환경에서 읽을 수 없음** — 예: NVIDIA GPU가 아니라 실시간 온도를 못 읽음, CPU에 온도 센서가 없음
- **이 프로필이 하지 않는 검사** — 예: 빠른 점검은 이벤트 로그를 조회하지 않음
- **따로 실행해야 하는 검사** — 예: VRAM 검사, GPU 부하 테스트

사유가 다르면 대처도 다릅니다. 앞의 둘은 **다른 프로필로 다시 돌리면** 해결되고,
마지막은 해당 검사를 직접 실행하면 됩니다.

### 판단 근거 강도

문제를 찾았을 때, 그 판정을 얼마나 믿을 수 있는지도 함께 표시합니다(전문가 모드).

| 값 | 뜻 |
|---|---|
| `CONFIRMED` | 측정으로 사실이 확인됨 |
| `STRONG_INDICATION` | 강한 연관성이 있지만 원인을 확정할 수는 없음 |
| `POSSIBLE_CAUSE` | 가능성 있는 원인 후보 |
| `NEEDS_VERIFICATION` | 추가 검사가 필요함 |

이 값은 사람이 정한 가중치이지 통계적으로 검증된 확률이 아닙니다.

### 권장 조치의 위험도

조치마다 "내가 해도 되는 일인지"를 뱃지로 표시합니다.
항상 **확인만 하는 안전한 조치가 먼저** 나옵니다.

| 위험도 | 예 |
|---|---|
| **안전** | 설정 확인, 값 읽기 — 시스템을 바꾸지 않음 |
| **낮음** | 먼지 제거, 드라이버 재설치 — 되돌리기 쉬움 |
| **중간** | BIOS 설정 변경 — 잘못하면 부팅이 안 될 수 있음 |
| **높음** | 전압·클럭 수동 조정 |
| **매우 높음** | BIOS 플래시 등 실패 시 복구가 어려움 |

## 6. 목적별 검사

| 프로필 | 예상 시간 | 부하 테스트 | 이럴 때 |
|---|---|---|---|
| **빠른 점검** | 25초 | 없음 | 지금 당장 눈에 띄는 문제가 있는지 |
| **전체 진단** | 60초 | 없음 | 수집 가능한 모든 항목 확인 |
| **게임 성능 진단** | 70초 | 짧게 | 게임 중 버벅거림·끊김의 원인 좁히기 |
| **안정성 검사** | 300초 | 길게 | 간헐적으로만 나타나는 문제 재현 |
| **중고 PC 점검** | 120초 | 있음 | 구매자에게 보여줄 리포트 발급 |
| **출고 전 검사** | 150초 | 있음 | 조립·정비 후 고객 전달 전 기록 |
| **수리 입고 검사** | 150초 | 있음 | 수리 전 상태 기록 |
| **수리 출고 검사** | 150초 | 있음 | 수리 후 기록 + 입고와 자동 비교 |

아래 네 가지는 **점검 리포트를 발급**하고 하드웨어 시리얼을 함께 기록하며,
검사 세션으로 남아 나중에 비교할 수 있습니다.

> ⚠ **안정성 검사를 실행하기 전에** — CPU와 저장장치를 5분간 밀어붙입니다. 온도 안전 한계에
> 도달하면 자동으로 중단되지만, 냉각이 부실한 PC라면 **먼저 먼지 상태를 확인**하세요.

검사가 끝나면 결과 아래에 **"이번 검사에서 확인하지 않은 것"**이 따로 나옵니다.
프로필이 원래 하지 않는 검사와, 이 환경에서 못 한 검사가 함께 적힙니다.

## 7. 평소 상태 기준선

절대 온도만으로는 "이 PC에서 뭔가 달라졌다"를 알 수 없습니다. 유휴 60°C는 어떤 PC에서는
정상이라 임계값을 전부 통과합니다.

먼지 누적이나 쿨러 열화처럼 **서서히 나빠지는 문제**는 "이 PC는 평소 44°C였다"는 정보가
있을 때만 보입니다.

### 측정 방법

1. **다른 프로그램을 모두 종료**하고 PC를 그대로 둡니다.
2. "평소 상태 기준선" 화면에서 **기준선 측정 시작**을 누릅니다.
3. 약 33초 동안 손대지 않고 기다립니다.

> **저장되지 않을 수도 있습니다.** 측정 중 부하가 걸리면 **저장하지 않고 이유를 알려줍니다**
> (예: "샘플 12개 중 4개만 유휴였고 최고 부하는 53%였습니다"). 부하 상태를 "평소"로
> 굳혀버리면 이후 모든 비교가 틀리기 때문입니다.

### 기준선이 쓰이는 방식

- 다음 진단부터 **"평소 44°C → 지금 60°C"**처럼 비교가 붙습니다.
- 차이가 **10°C 이상이면 지켜보기**, **15°C 이상이면 주의**로 올립니다.
  실내 온도만으로 설명하기 어려운 폭이기 때문입니다.
- **진단할 때 PC가 유휴가 아니면 비교하지 않습니다.** 게임 중 온도를 유휴 기준선과
  비교하면 무조건 "이상"이 나오기 때문입니다.
- CPU를 교체하면 그 기준선은 다른 PC의 값이므로 자동으로 쓰지 않습니다.

### 언제 다시 측정하나

기준선은 시간이 지났다고 자동으로 지워지지 않습니다(그러면 정작 몇 달에 걸친 변화를 못 잡습니다).
대신 **계절이 바뀌어 실내 온도가 크게 달라졌거나**, **쿨러·서멀 그리스를 새로 손봤거나**,
**상주 프로그램을 크게 정리했다면** 다시 측정해 새 기준으로 삼으세요.

## 8. 안정성 테스트

"부하 테스트" 화면에서 5가지를 직접 실행할 수 있습니다. 모두 중단 버튼이 있습니다.

| 테스트 | 무엇을 보나 | 안전장치 |
|---|---|---|
| **CPU 부하 테스트** | 고부하에서 온도·클럭이 버티는지 | 설정한 온도 도달 시 자동 중단 |
| **저장장치 처리량** | 실제 파일 읽기/쓰기 속도와 I/O 오류 | 앱 임시 폴더에만 씀, 여유 공간 확인 |
| **RAM 무결성 간이검사** | 패턴 3종으로 쓴 값이 그대로 읽히는지 | 크기 상한 제한 |
| **GPU 부하 테스트** | 고부하에서 온도 상승·클럭 하락 | 안전 온도 초과 시 자동 중단 |
| **VRAM 압박 · 무결성** | 그래픽 메모리에 쓴 값이 그대로 되읽히는지 | 끝나면 VRAM 즉시 반납 |

> ⚠ **GPU·VRAM 테스트 중에는 창을 가리지 마세요.** 창을 최소화하거나 완전히 가리면
> 렌더링이 멈춰 **부하가 실제로 걸리지 않습니다.** 이 경우 프로그램은 "정상"이라고 하지 않고
> **판단 보류**로 처리하고 이유를 알려줍니다.

### 속도가 느리게 나온다면

저장장치 처리량은 HDD·SATA SSD·NVMe에 따라 수십 배 차이가 납니다. 그래서 **속도만으로는
고장이라고 판정하지 않습니다.** I/O 실패나 데이터 불일치처럼 장치 종류와 무관한 것만
문제로 올립니다.

### 결과가 진단에 반영되는 방식

GPU 부하 테스트와 VRAM 검사는 **결과가 기록되어 다음 진단의 근거**로 쓰입니다(30일 유효).
CPU·저장장치·RAM 부하 테스트는 점검 리포트를 발급하는 프로필에서 자동으로 함께 실행됩니다.

## 9. 개별 장치 테스트

### 디스플레이

소프트웨어가 자동으로 판정할 수 없는 항목입니다. **사람이 눈으로 보고**
"이상 없음 / 이상 발견"을 직접 기록합니다. 기록한 결과는 다음 진단의 디스플레이 항목에

- **불량화소 테스트** — 단색 화면을 띄워 죽은 화소·밝은 점을 찾습니다

- **그라데이션 밴딩** — 색 계단 현상을 확인합니다
- **밝기 균일도** — 화면 모서리와 가운데의 밝기 차이를 봅니다

### 마우스

**더블클릭 오작동 테스트**가 핵심입니다. 한 번 눌렀는데 두 번 입력되는 채터링을 잡아냅니다.

### 키보드

눌린 키가 화면에 표시됩니다. 특정 키가 반응하지 않거나 누르지 않았는데 입력되는지 확인합니다.

### 네트워크

지연시간(핑), 변동폭(지터), 패킷 손실을 측정합니다. Wi-Fi에서 결과가 나쁘면 유선으로 바꿔
다시 측정해 회선 문제인지 무선 구간 문제인지 가릅니다.

## 11. 점검 리포트

중고 거래나 수리·출고 시 상대방에게 전달할 수 있는 문서입니다.

### 문서에 담기는 것

| 항목 | 내용 |
|---|---|
| 검사 ID | `DB-20260813-6FC7151E` 형식의 고유 식별자 |
| 등급 | A+ / A / B / C / D — 성능이 아니라 **이상 여부**만 반영 |
| 영역별 점수 | 하드웨어·발열·저장장치·안정성·소프트웨어 |
| 검사 범위 | 무엇을 검사했고 **무엇을 검사하지 않았는지** 전부 명시 |
| 측정값 | 최고 온도, 최고 사용률, SMART 상세 등 실제 수치 |
| 하드웨어 식별 | 시리얼은 뒤 4자리만 표시하고 나머지는 마스킹 |
| 검증 코드 | 내용 전체의 SHA-256 해시. 값 하나만 바뀌어도 검증 실패 |
| 버전 | 어느 버전이 어떤 규칙으로 낸 판정인지 |
| 유효기간 | 발급 후 7일 |

### 저장

**HTML**과 **PDF** 중에 고를 수 있습니다. 화면에 보이는 문서와 저장되는 파일은 완전히 같은
내용입니다. PDF는 상세 설명을 모두 펼친 상태로 굳혀 저장하고, HTML은 화면처럼 접힌 상태로
저장해 나중에 클릭해 펼칠 수 있습니다.

### 🔴 이 문서가 주장하지 않는 것

점검 리포트는 **"이 PC는 고장이 없습니다"라고 말하지 않습니다.** 검사 시점에 지정된 항목을
검사한 결과를 기록할 뿐입니다. 검사 이후에 고장이 날 수 있고, 검사하지 않은 항목은
확인되지 않은 상태 그대로입니다.

법적 인증서가 아니며 정부 성능인증 제도와 무관합니다. 문서 본문에도 같은 내용이 명시됩니다.

### QR 코드와 검증 (v0.31.0~)

QR은 완전히 로컬에서 생성됩니다(서버 없음, 오프라인 동작).
스캔하면 **웹 검증 페이지**로 이동합니다 — https://thisismo0614.github.io/DIAG.BENCH/verify.html

리포트를 **HTML로 저장**하면 문서 안에 검증코드 계산에 쓰인 원본 자료가 함께 들어갑니다.
그 파일을 검증 페이지에 올리면 브라우저가 SHA-256을 다시 계산해 대조합니다.
파일은 어디로도 전송되지 않고 브라우저 안에서만 처리되며, 앱을 설치하지 않은 사람도
확인할 수 있습니다.

> **PDF로는 검증할 수 없습니다.** PDF에는 원본 자료가 들어가지 않습니다.
> 검증까지 하려면 HTML로 저장한 파일을 함께 전달하세요.

**이 검증이 보증하는 범위를 정확히 알아둘 것:**

| 확인해 줍니다 | 확인해 주지 못합니다 |
|---|---|
| 문서에 심긴 원본 자료가 발급 이후 바뀌지 않았다는 것 | 이 리포트가 진짜 그 PC에서 발급됐다는 것 |

- **화면에 보이는 글자는 해시 대상이 아닙니다.** 누군가 문서의 보이는 글자만 고쳐도 검증코드는
  그대로 일치합니다. 그래서 검증 페이지는 통과 시 **"검증코드가 실제로 보증하는 값"**(등급,
  검사 범위, 고객 기록 등)을 함께 표시합니다. 받은 문서와 그 값을 대조하세요.
- **위조 방지가 아니라 변조 감지입니다.** 소스가 공개되어 있어 마음먹으면 값을 고친 뒤 해시를
  다시 계산할 수 있습니다. 서버가 발급 사실을 보증하는 전자서명은 아직 없습니다.
- 구매자라면 **같은 PC에서 직접 재실행해 대조**하는 것이 가장 확실합니다.

v0.31.0 이전에 발급한 리포트에는 원본 자료가 없어 이 페이지로 검증할 수 없습니다.
그 경우 앱에서 불러와 확인하세요.

## 12. 전후 비교

"무엇이 실제로 좋아졌는가"를 데이터로 보여줍니다.

### 수리점 흐름

1. 고객 PC를 받으면 **수리 입고 검사**를 실행합니다.
2. 수리·정비를 진행합니다.
3. **수리 출고 검사**를 실행합니다. 같은 PC의 가장 최근 입고 검사를
   **자동으로 찾아 비교표**를 만듭니다.

두 프로필은 검사 범위가 완전히 같도록 맞춰져 있습니다. 범위가 다르면 비교 자체가
성립하지 않기 때문입니다.

### 비교되는 항목

CPU·GPU 최고 온도, 메모리 동작 속도, 하드웨어 오류(WHEA)·예기치 않은 종료·블루스크린 건수,
드라이버 오류 장치 수, RAM 검사 오류, 저장장치 읽기/쓰기 속도, 그리고 등급 변화.

> **비교하지 않는 경우** — 한쪽에서 측정되지 않은 항목은 **"비교 불가"**로 남깁니다.
> 입고 때 GPU 온도를 못 쟀는데 출고 때 75°C가 나왔다고 개선이라 할 수 없기 때문입니다.
> 한쪽만 부하 테스트를 했다면 부하가 필요한 항목도 비교에서 뺍니다.
> 저장장치 속도는 실행할 때마다 흔들리므로 **10% 이상 차이**가 나야 변화로 봅니다.

### 하드웨어 구성 대조

두 세션의 CPU·GPU·메모리·저장장치 식별값을 나란히 놓고 일치하는지 확인합니다.
중고 거래에서 "받은 PC가 그때 그 PC인지" 대조하는 용도입니다.

다만 이것은 **부품이 동일하다는 인증이 아닙니다.** OS에서 읽을 수 있는 모델·시리얼을
대조할 뿐이며, 식별값을 읽을 수 없는 부품이나 물리적 교체까지 확인하지는 못합니다.

임의의 두 세션을 직접 골라 비교하려면 **"전후 비교"** 화면에서 이전/이후를 선택하고
"비교"를 누릅니다.

## 13. 해결 Wizard

문제를 찾았을 때 "그래서 뭘 해야 하나"를 단계로 안내합니다. 진단 결과의 문제 카드에서
**"단계별 해결 방법"**을 펼치세요.

각 단계에는 위험도가 붙어 있고, 필요한 경우 **해당 검사 화면으로 바로 이동하는 버튼**이
있습니다. 절차는 보통 이런 모양입니다.

1. **현재 상태 확인** (안전) — 무엇이 문제인지 값으로 확인
2. **현재 설정 기록** (안전) — 되돌릴 수 있도록 먼저 남김
3. **지금 상태에서 안정성 검사** (안전) — 기준점 만들기
4. **설정 변경** (중간) — BIOS 등 실제 조치
5. **재검사** (안전) — 실제로 개선됐는지 확인

**마지막 단계는 항상 재검사입니다.** "고쳤다"로 끝나면 개선됐는지 알 수 없기 때문입니다.

> ⚠ **되돌리기 어려운 단계가 있으면** 절차 맨 위에 경고가 먼저 뜹니다.
> **시작하기 전에 현재 설정을 사진이나 메모로 남기세요.** BIOS 설정을 잘못 바꾸면 부팅이
> 되지 않을 수 있으며, 그때는 CMOS 클리어로 복구합니다.
> 반대로 안전한 단계만 있는 절차에는 이 경고가 붙지 않습니다.

이 프로그램은 **설정을 자동으로 바꾸지 않습니다.** 진단과 안내까지만 하고,
실제 변경은 사용자가 직접 합니다.

## 14. 하지 않는 것

할 수 없는 것을 분명히 밝히는 것도 진단 도구의 일입니다.

### 측정할 수 없는 항목

| 항목 | 이유 |
|---|---|
| GPU 실시간 온도·부하·클럭 | **NVIDIA만** 지원합니다. AMD·Intel 내장은 모델과 VRAM 용량만 읽습니다 |
| CPU 온도 | 센서를 노출하지 않는 CPU·메인보드가 있습니다. 그런 PC에서는 "검사 안 함"으로 표시됩니다 |
| 메모리 타이밍 (CL·tRCD·tRP) | OS에서 읽을 수 있는 방법이 없습니다. 별도 커널 드라이버가 필요합니다 |
| XMP·EXPO 프로파일 목록 | 같은 이유로 조회할 수 없습니다. 대신 **"정격 대비 현재 속도"**라는 측정 가능한 사실만 말합니다 |
| CPU 전압 | 대부분의 메인보드가 OS에 노출하지 않습니다. 언더볼팅 여부는 확인 불가로 표시됩니다 |
| 배터리·팬 RPM·전원 | 노트북 대응과 PSU 진단은 아직 없습니다 |
| HDR·색영역 정밀 측정 | 측정 장비가 필요한 영역입니다 |

### 다른 도구를 대체하지 않는 것

- **RAM 무결성 검사**는 간이 검사입니다. 부팅형 정밀 검사(MemTest86 등)를 대체하지 않습니다.
- **VRAM 검사**도 간이 검사입니다. 드라이버가 사본을 갖고 있으면 셀 오류를 놓칠 수 있습니다.
- **SMART**는 디스크가 스스로 보고하는 값입니다. 보고하지 않는 고장은 알 수 없습니다.

### 아직 없는 기능

- 온라인 검증 페이지 — 검사 ID로 원본 기록을 조회하는 웹 서비스
- 업체용 대시보드·다중 PC 관리·고객 식별
- 코드 서명 — SmartScreen 경고가 뜹니다
- 자동 업데이트 — 새 버전은 직접 받아 설치합니다
- 백그라운드 상시 모니터링 — 앱이 켜져 있을 때만 측정합니다

## 15. 자주 묻는 질문

**전부 초록색이 아닌데 고장인가요?**
아닙니다. 회색 "검사 안 함"은 문제가 아니라 **확인하지 않았다는 정직한 표시**입니다.
다른 프로필로 다시 검사하면 대부분 채워집니다.

**드라이버 오류 장치가 있다고 나옵니다.**
장치관리자에서 오류 상태인 장치가 있다는 뜻입니다. 대개 메인보드 칩셋 드라이버를 설치하지
않아 생깁니다. 메인보드 제조사 홈페이지에서 칩셋 드라이버를 받아 설치하면 해결되는 경우가 많습니다.

**같은 PC인데 검사할 때마다 결과가 조금씩 다릅니다.**
온도·부하·처리량은 그때그때 달라지는 값입니다. 그래서 이 프로그램은 **미세한 변화를
개선/악화라고 부르지 않고**, 항목마다 무시 임계값을 둡니다.

**등급이 낮게 나왔는데 하드웨어는 멀쩡해 보입니다.**
등급은 하드웨어만 보지 않습니다. Windows 이벤트 로그의 재부팅·오류 기록, 드라이버 상태도
함께 반영됩니다. 결과 화면의 **"왜 이 등급인지"**와 **"어디는 정상인지"**를 함께 보세요.

**검사 중에 PC를 써도 되나요?**
부하 테스트와 기준선 측정은 **손대지 않는 것**이 좋습니다. 다른 작업이 섞이면 측정값이
그 작업의 것이 됩니다. 기준선 측정은 부하가 감지되면 아예 저장하지 않습니다.

**기록은 어디에 저장되나요?**
모두 이 PC 안에만 저장됩니다(사용자 데이터 폴더). 외부로 전송하지 않습니다.
진단 기록·검사 세션·기준선은 각 화면에서 직접 삭제할 수 있습니다.

**중고로 산 PC를 확인하고 싶습니다.**
**중고 PC 점검** 프로필을 실행하세요. 판매자가 준 리포트가 있다면, 내 검사 결과와
[전후 비교](#12-전후-비교)에서 하드웨어 구성을 대조할 수 있습니다.
설정 변경(오버클럭) 여부와 저장장치 사용 시간도 함께 확인하세요.
